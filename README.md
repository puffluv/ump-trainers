# Тренажёры курса «Управление мультимедиа проектами»

Сайт из статических страниц: открывается в браузере, в том числе с телефона,
ничего не нужно устанавливать. Результаты зачётных проходов приходят
преподавателю в Яндекс Форму и выгружаются в Excel.

**Адрес стенда:** https://puffluv.github.io/ump-trainers/
**Кабинет преподавателя:** https://puffluv.github.io/ump-trainers/teacher.html

## Что в папке

В каждом тренажёре два набора заданий: один для зачётного прохода, другой —
для самопроверки. Самопроверка не повторяет зачёт.

| Файл | Что это |
|---|---|
| `index.html` | Главная: вход по коду комнаты и список тренажёров |
| `trainer-project-or-process.html` | Тема 1, лекция 1: «Проект или процесс», по 12 ситуаций в каждом наборе |
| `trainer-requirements.html` | Тема 2, лекция 2: «Проверяемые требования», по 10 формулировок |
| `critical-path.html` | Тема 2, лекция 3: сетевой график и по 7 заданий к нему |
| `trainer-defects.html` | Дополнительно, вне тем курса: «Классификация замечаний», по 12 замечаний |
| `teacher.html` | Кабинет преподавателя: комната, QR-код, разбор результатов |
| `consent.html` | Согласие на обработку персональных данных — отдельный документ |
| `config.js` | Настройки: ссылка на форму и сведения об операторе данных |
| `kurs.js`, `kurs.css`, `kurs-data.js`, `qr.js` | Общий код, оформление, содержание заданий, генератор QR |

## Как это устроено

1. Преподаватель создаёт в кабинете комнату — получает код из 5 знаков,
   ссылку и QR-код.
2. Студент открывает тренажёр по QR или вводит код на главной. Код можно
   набрать и русскими буквами.
3. В зачётном режиме студент указывает фамилию, имя и группу и отмечает
   согласие на обработку персональных данных.
4. В конце тренажёр открывает Яндекс Форму, в которую уже подставлены
   результат, номера заданий с ошибками, время прохождения и контрольный код.
   Студент нажимает «Отправить».
5. Преподаватель выгружает ответы формы в Excel и вставляет таблицу
   в кабинет. Кабинет проверяет контрольные коды, строит сводку и выгружает
   CSV для журнала.

В режиме самопроверки ничего не отправляется.

**Где хранятся данные.** Сайт ничего не хранит и никуда не отправляет сам.
Фамилия, имя и группа попадают только в Яндекс Форму преподавателя,
и только после нажатия «Отправить». GitHub Pages отдаёт страницы и видит
адреса посетителей, как любой хостинг, но введённые данные к нему не попадают.

## 1. Создать Яндекс Форму

1. Войдите на [forms.yandex.ru](https://forms.yandex.ru) своей учётной
   записью Яндекса и создайте новую форму «Результаты тренажёров».
2. Добавьте вопрос типа «Короткий текст» с заголовком «Комната». В настройках
   вопроса включите «Скрытый вопрос» и в поле «Идентификатор вопроса» укажите
   `room`.
3. Так же добавьте ещё девять скрытых вопросов из таблицы ниже. Заголовки
   важны: по ним кабинет находит колонки в выгрузке.
4. Рекомендуется добавить один видимый обязательный вопрос: согласие на
   обработку персональных данных со ссылкой на страницу `consent.html`
   вашего сайта.
5. Опубликуйте форму и скопируйте её ссылку.
6. Вставьте ссылку в `config.js`, в строку `formUrl` (см. часть 2, шаг 6).
   Там же заполните раздел `operator` — кто обрабатывает данные. Текст
   согласия стоит согласовать с вузом.
7. Проверка: в кабинете откройте «Настройка Яндекс Формы» → «Открыть форму
   с тестовыми данными» → «Отправить». Выгрузите ответы в Excel и вставьте
   в раздел «Результаты»: в колонке «Проверка» должна стоять галочка.

| Заголовок вопроса | Идентификатор |
|---|---|
| Комната | `room` |
| ФИО | `fio` |
| Группа | `group` |
| Тренажёр | `trainer` |
| Баллы | `score` |
| Всего заданий | `total` |
| Ошибки | `mistakes` |
| Длительность, с | `seconds` |
| Контроль | `check` |
| Согласие | `consent` |

Если какой-то колонки нет в выгрузке, проверьте идентификатор этого вопроса.

## 2. GitHub Pages

Стенд уже опубликован: репозиторий
[github.com/puffluv/ump-trainers](https://github.com/puffluv/ump-trainers),
ветка `main`, папка `/`. Эта папка на компьютере — рабочая копия репозитория.

**Обновить стенд** — любым из способов, сайт обновится примерно через минуту:

- на github.com открыть нужный файл, нажать значок карандаша, исправить
  и сохранить кнопкой «Commit changes»;
- или изменить файлы в этой папке и выполнить в ней
  `git add -A`, `git commit -m "что изменено"`, `git push`.

Браузеры хранят файлы стенда до 10 минут. `config.js` всегда загружается
свежим, поэтому правка настроек действует сразу. Если меняете `kurs.js`,
`kurs-data.js`, `kurs.css` или `qr.js`, поменяйте во всех HTML-файлах номер
версии в ссылках на них (`?v=…`) — иначе у студентов до 10 минут будет
открываться старая версия.

**Развернуть заново под другим аккаунтом** (например, на аккаунте
преподавателя):

1. Войдите на [github.com](https://github.com) или зарегистрируйтесь.
2. Создайте репозиторий кнопкой «New repository», видимость Public.
3. На странице репозитория выберите «uploading an existing file», перетащите
   все файлы из этой папки (саму папку не нужно) и нажмите «Commit changes».
4. Откройте Settings → Pages. В разделе «Build and deployment» выберите
   Source «Deploy from a branch», ветку `main`, папку `/ (root)` и нажмите
   «Save».
5. Через одну-две минуты сайт откроется по адресу
   `https://<логин>.github.io/<имя-репозитория>/`. Проверьте форму по
   части 1, шаг 7.

Репозиторий публичный: исходный код и содержание заданий видны всем.
Персональных данных в нём нет — они попадают только в Яндекс Форму.
Подойдёт и любой другой статический хостинг: достаточно скопировать папку
целиком.

## 3. Провести занятие

1. Откройте кабинет преподавателя по адресу стенда, а не как файл
   с компьютера: иначе телефоны студентов не откроют ссылку из QR-кода.
2. Выберите тренажёр и нажмите «Создать комнату и показать QR»: QR-код
   откроется на весь экран. Запишите код комнаты.
3. Студенты наводят камеру телефона на QR-код и сразу попадают в зачётный
   проход этой комнаты. Можно и вручную: открыть главную и ввести код.
4. Студенты указывают фамилию, имя и группу, отмечают согласие и проходят
   задания.
5. В конце каждый нажимает «Открыть форму и отправить», а затем «Отправить»
   в самой форме.
6. После занятия выгрузите ответы формы в Excel, скопируйте таблицу вместе
   со строкой заголовков, вставьте в кабинет и нажмите «Разобрать».
   Отфильтруйте по коду комнаты.
7. Кнопка «Скачать для Excel (CSV)» сохраняет итог для журнала.
8. Если форма недоступна, студенты присылают код результата (строка
   `UMP1.…`). Вставьте коды туда же, куда таблицу.

## Что важно знать

- **Контрольный код** показывает, что числа в выгрузке не правили вручную.
  От студента, который прочитает исходный код страницы, он не защищает:
  сервера нет, и это осознанный выбор ради простоты и того, чтобы не хранить
  персональные данные.
- **Два набора заданий.** Самопроверка и зачётный проход используют разные
  задания, поэтому самопроверка не превращается в репетицию зачёта. Оба набора
  лежат в `kurs-data.js` — и он публичный, как и весь сайт.
- **Повторные попытки.** Каждая отправка — отдельная строка. Кабинет помечает
  повторные попытки, а какую засчитывать, решает преподаватель.
- **Без интернета** тренажёры работают в режиме самопроверки, а вместо
  фирменного шрифта будет системный.
- **Номера заданий** в выгрузке берутся из `kurs-data.js`. Их нельзя
  перенумеровывать, иначе старые выгрузки разойдутся с заданиями.
- **Светлая тема** — кнопка в правом верхнем углу. Удобна для проектора
  в светлой аудитории; по ссылкам внутри сайта переносится.
